## Run locally

### Backend (Express)
- `cd backend`
- Copy `backend/.env.example` to `backend/.env` and set values
- `npm install`
- `npm start`

### Frontend (React + Vite)
- `cd frontend`
- `npm install`
- `npm run dev`

If PowerShell blocks `npm` script execution, use `npm.cmd` instead (example: `npm.cmd run dev`).

## Frontend environment
- Optional `VITE_API_ORIGIN` (example: `http://localhost:5000`)
- Optional `VITE_API_BASE_URL` (example: `http://localhost:5000/api`)
